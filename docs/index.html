Возможности

Всё нужное для контроля API-квот — в одном нативном окне

Собрано на Tauri v2, React 19 и Rust: весит около 6 МБ, не грузит память как Electron и работает прямо из системного трея Windows.

Квота, RPM/TPM и динамика

Кольцевой индикатор остатка, фактический расход со скидкой, статистика за сегодня/всего, прогноз дней до конца лимита и график за 14 дней.

Аудит Prompt Cache + Heatmap

Тепловая карта активности за 22 недели с переключением режима ($ / Токены / Запросы) и расчёт реальной экономии от кэширования по каждой модели.

Живой каталог тарифов и Monitor

Цены за 1M токенов и коэффициенты групп с true-sota.com/model-pricing, проверка доступных вашему ключу моделей и пинг API-шлюза.

Системный трей и алерты Windows

Сворачивание в трей по ×, тихий автозапуск с Windows, остаток квоты в подсказке трея и уведомления при падении баланса ниже порога.

Dynamic Island и Ctrl+K

Плавающий мини-виджет поверх всех окон по Alt+I, мгновенная командная палитра Ctrl+K и переключение 620×900 ↔ 1920×1080.

Экспорт отчётов и обновления

Генератор карточки 16:9 PNG, копирование сводки, экспорт в CSV/Markdown в папку Downloads и проверка свежих релизов на GitHub.

Безопасность и приватность

Ваш API-ключ никогда не покидает ваш компьютер в открытом виде

В программе нет зашитых или чужих токенов. Исходный код полностью открыт для проверки.

01 · INPUT

Ваш API-ключ

Вы вставляете личный токен при первом входе или меняете его в настройках.

02 · ENCRYPT

Windows DPAPI

Rust-бэкенд шифрует ключ через CryptProtectData с привязкой к профилю Windows.

03 · STORAGE

%APPDATA%\TrueSOTA_Monitor

На диске лежит только зашифрованный блоб; рядом с .exe ничего не хранится.

04 · DIRECT HTTPS

Только TrueSOTA & GitHub

Запросы идут напрямую на true-sota.com и endpoint релизов GitHub.
