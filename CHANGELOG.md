# Changelog

Все заметные изменения проекта **TrueSOTA Usage Monitor** фиксируются в этом файле.

---

## [v1.2.0] — 2026-11-12

### Изменения и улучшения
- **Чистый Pure OLED интерфейс:** удалён лишний blur-слой `AppleLiquidNav` / `liquid-glass-react` ради чистого `#000000` OLED-контраста и плавных анимаций `SmoothTab`.
- **Портретный режим по умолчанию (`620×900`):** компактный дашборд с переключением пресетов размера (`620×900`, `880×880`, `1600×940`, `1920×1080` / Fullscreen).
- **Интерактивный веб-симулятор и документация:** добавлен сайт-демо в `docs/` для GitHub Pages, англоязычный `README.en.md`, политика безопасности `SECURITY.md` и CI/CD workflow.

---

## [v1.1.0] — 2026-11-11

### Добавлено
- **Шифрование Windows DPAPI:** безопасное локальное хранение личного API-ключа через `CryptProtectData` в `%APPDATA%\TrueSOTA_Monitor\truesota_config.json`.
- **Системный трей и автозапуск Windows:** сворачивание в трей по нажатию `×`, остаток квоты в подсказке трея и тихий запуск с системой.
- **Уведомления Windows:** алерты при снижении остатка квоты ниже заданного порога и при сбое/восстановлении API.
- **Проверка обновлений:** встроенный чекер актуальной версии через `GitHub Releases`.

---

## [v1.0.0] — 2026-11-11

### Первый релиз
- Нативное настольное приложение на **Tauri v2**, **React 19** и **Rust** для Windows 10 / 11.
- Обзор квоты, дневной/общий расход, статистика по моделям, каталог тарифов, аудит Prompt Cache, 22-недельный Heatmap, командная палитра `Ctrl+K`, Dynamic Island (`Alt+I`) и экспорт отчётов.
