# TrueSOTA Usage Monitor

Настольная программа для Windows, которая позволяет в реальном времени следить за балансом, расходом квот, тарифами моделей и работой серверов **TrueSOTA** прямо с рабочего стола.

> В программе нет встроенных или чужих API-ключей — при первом запуске каждый пользователь вводит свой личный ключ. Он хранится только локально на вашем компьютере в `%APPDATA%\TrueSOTA_Monitor\truesota_config.json`.

---

## Что умеет программа

- **Мониторинг баланса и расхода** — отображает общий лимит, остаток квоты, расходы за период, токены, количество запросов и статистику кэширования (Prompt Cache) по каждой модели.
- **График активности по дням** — таблица активности за 22 недели (`Расход $` / `Токены` / `Запросы`) и счётчик серий.
- **Каталог тарифов и доступных моделей** — актуальные цены и коэффициенты групп с `https://true-sota.com/model-pricing`, проверка доступных моделей по вашему ключу и копирование ID модели в один клик.
- **Мониторинг каналов и пинг API** — встроенная вкладка со страницей `https://true-sota.com/monitor` и проверкой задержки ответа API-шлюза.
- **Мини-виджет и быстрое меню (`Ctrl+K`)** — компактный режим поверх всех окон, настройка интервала автообновления и быстрый доступ к действиям по `Ctrl+K`.
- **Экспорт статистики** — сохранение карточки в PNG, копирование в буфер обмена и выгрузка отчётов в `CSV` и `Markdown` в папку `Downloads`.

## Установка и безопасность

1. Запустите любой из установщиков:
   - **`TrueSOTA_Installer.exe`** — стандартный установщик для Windows (NSIS, рекомендуется).
   - **`TrueSOTA_Setup.msi`** — установщик формата Microsoft Installer (MSI).
   *(Также доступна переносная версия `TrueSOTA_Monitor_Tauri.exe`, не требующая установки.)*
2. Если Windows SmartScreen покажет предупреждение о неизвестном издателе, нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. При первом запуске введите **собственный API-ключ TrueSOTA** — программа отправляет запросы только на `https://true-sota.com`, а ключ хранится только в вашем профиле Windows (`%APPDATA%\TrueSOTA_Monitor\truesota_config.json`).
